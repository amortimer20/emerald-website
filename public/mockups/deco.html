EMERALD

A language for learning to program

Clear code that reads like what it does, and errors that explain themselves. Built for the classroom, from the first print to the first class.

Start learning Read the docs

Reads like what it does

No ceremony before the first line. Types when they help, never when they don't.

gems.em 
struct Gem {
    const name: String
    const carats: Float
}

const gems = [Gem("Emerald", 2.5), Gem("Ruby", 1.25)]
for gem in gems {
    print("#{gem.name}: #{gem.carats} carats")
}
Output
Emerald: 2.5 carats
Ruby: 1.25 carats
