Under the loupe

Code that reads like what it does, and a close eye for the mistakes that slip in.

gems.em 
struct Gem {
    const name: String
    const carats: Float
}

const gems = [Gem("Emerald", 2.5), Gem("Ruby", 1.25)]
for gem in gems {
    print("#{gem.name}: #{gem.carats} carats")
}
Emerald: 2.5 carats
Ruby: 1.25 carats

Built-ins · Types

Float

A number that can have a fractional part, such as 3.14 or -0.5.

clamp(minimum: Float, maximum: Float): Float

The value, kept within minimum to maximum. A value below the range becomes minimum, and a value above it becomes maximum.

12.7.clamp(0, 10)   # → 10.0
-3.0.clamp(0, 10)   # → 0.0
4.2.clamp(0, 10)    # → 4.2

Raiseswhen minimum is greater than maximum.

round(): Int

The nearest whole number. A value exactly halfway rounds away from zero.

2.5.round()    # → 3
-2.5.round()   # → -3
