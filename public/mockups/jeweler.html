Graded for clarity

Gemologists judge a stone by its cut, clarity, and color. We hold a language to the same standard.

Language grading report

Clean and simpleOne readable way to write each idea, kept tidy by a built-in formatter.
Clarity

Color
Vivid, never loudTypes when they help, inferred when they don't, and no ceremony before the first line.
Carat

Under the loupe

Code that reads like what it does, and a close eye for the mistakes that slip in.

struct Gem {
    const name: String
    const carats: Float
}

const gems = [Gem("Emerald", 2.5), Gem("Ruby", 1.25)]
for gem in gems {
    print("#{gem.name}: #{gem.carats} carats")
}
