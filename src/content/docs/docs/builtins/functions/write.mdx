<p class="reference-facts">Built-in function · Available everywhere, with no import</p>

`write` is [`print`](../print/) without the new line at the end, so several `write`s build
up a single line.

```emerald
for n in 1..3 {
    write(n, "")
}
print()
# prints 1 2 3 on one line
```

<Member name="write" params="values...">

Shows each value, separated by a space, exactly as `print` does, but does not end the line.

</Member>
